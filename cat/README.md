# Base cat (vector rig)

- `cat_base.py` — Pillow renderer (GIF / compare / stills)
- `cat-base.js` — canvas `drawBaseCat(ctx, {x,y,scale,t,walkPhase,...})`
- `cat-base.svg` — static SVG with part groups + pivots

Parts: tail, legs, body, arms, head, ears, eyes, blush, mouth, whiskers, stripes.
Idle: breath, blink, ear twitch, tail sway. Pass `walkPhase` for walk.
