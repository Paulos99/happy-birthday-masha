# С днём рождения, Маша 🎂🎭

Вечерний scrapbook-театр на проектор: тёплый свет, гирлянды, коты-дудлы со своими ролями и сценарием из ~22 актов.

**Live:** https://paulos99.github.io/happy-birthday-masha/

## Тексты — `config.js`

Имя, возраст, дата, заголовок, пожелания (стикер), комплименты (пузыри), подписи полароида, баннер «Маша — самая лучшая», тосты/реплики gag-сцен, UI.

Имя также: `?name=Маша`.

## Фото — `photos.js`

```js
window.PHOTOS = ['photos/1.jpg', 'photos/2.jpg'];
```

Кот-фотограф обновляет полароид по сценарию.

## Роли котов

| Кот | Место | Дело |
|-----|-------|------|
| Бросатель | облако сверху | конфетти и снег |
| Лесенка | лестница | вешает флажки |
| Насос | справа | надувает шары |
| Фотограф | сцена | меняет полароид |
| Писатель | у стикера | пишет пожелания |
| Пекарь | стол с тортом | зажигает свечи |
| Музыкант | справа | гитара + ноты |
| Танцор A/B | низ | танцуют (иногда застенчивого тянут) |
| Крутой | справа | очки + peace |
| Говорун | середина | комплименты Маше |
| Шар | слева | сердце-шар (иногда улетает) |
| Сонный | коробка | выпрыгивает из подарка |

Сценарий циклом: открытие → гирлянда → шары → письмо → фото → проказы → буквы МАША → баннер → общий кадр → тост → поклон → idle…

## Полный экран

Кнопка-лапка, **F**, двойной клик.
