# С днём рождения, Маша 🎂

Scrapbook-заставка на проектор: бумажный фон, буквы на квадратиках, полароид, стикер и коты-дудлы.

**Live:** https://paulos99.github.io/happy-birthday-masha/

## Тексты — `config.js`

| Поле | Что это |
|------|---------|
| `name` | Имя (ещё: `?name=`) |
| `age` | Цифра «24» |
| `dateLine` | Дата |
| `title` | Заголовок по буквам |
| `wishes` | Текст на розовом стикере (меняет кот с карандашом) |
| `compliments` | Реплики в пузыре говорящего кота |
| `polaroidCaption` / `photoCaptions` | Подпись полароида |
| `ui.*` | Кнопка и подсказка |

## Фото — `photos/` + `photos.js`

```js
window.PHOTOS = ['photos/1.jpg', 'photos/2.jpg'];
```

Пустой список → сердечко-заглушка. Кот-фотограф обновляет полароид roughly каждые 30 секунд.

## Зоны макета

1. **Верх** — заголовок и имя (ransom-tiles)  
2. **Середина** — полароид + стикер + большая «24» (текст защищён)  
3. **Низ (~22%)** — сцена с котами (на текст не заходят)  
4. **Угол неба** — кот кидает конфетти и снег (все падающие частицы только от него)

## Коты

Бросатель · фотограф · стикер · торт · говорун · танцор · музыкант · шар-сердце · крутой (очки + peace)

Форма: белый дудл, толстый контур, 3 полоски на лбу, румяна, рот ω / язычок, короткий хвост, × на животе, колпак со звездой.

## Полный экран

Кнопка-лапка (прячется), **F**, двойной клик.
