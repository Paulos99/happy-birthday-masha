# С днём рождения, Маша 🎂🐱

Праздничная анимированная заставка на проектор: пастель, гирлянды, коты в колпачках.

**Live:** https://paulos99.github.io/happy-birthday-masha/

## Тексты

Все строки — в **`config.js`**: имя, возраст, дата, поздравления, пожелания, комплименты говорящего кота, подписи к фото, тексты табличек, UI.

Имя также можно передать `?name=Маша`.

## Фото для кота-фотографа

1. Файлы в `photos/`
2. Пути в `photos.js` → `window.PHOTOS`
3. Пуш в `main`

Пока список пустой — заглушки с сердечком.

## Рисование котов

Форма сейчас простая (chibi). Чтобы подменить по референсу — правь функцию `drawCatBody()` в `index.html`. Колпачки и короткие хвосты уже встроены.

## Полный экран

Кнопка-лапка, клавиша **F**, двойной клик.
