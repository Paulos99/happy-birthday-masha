# С днём рождения, Маша 🎂🐱

Анимированная заставка на проектор: тёплый тёмный фон, снег, свечи и милые коты-NPC.

**Live:** https://paulos99.github.io/happy-birthday-masha/

## Открыть

- Просто: https://paulos99.github.io/happy-birthday-masha/
- С именем из URL: `?name=Маша` (по умолчанию уже Маша)
- На весь экран: кнопка с лапкой, клавиша **F** или двойной клик

## Коты и их роли

| Кот | Роль |
|-----|------|
| Сонный | Дремет на цифре «24», иногда просыпается и потягивается |
| С табличкой | Выходит и меняет поздравления / пожелания |
| Фонарщик | Зажигает гирлянду и свечи на торте |
| С шариком | Плывёт через экран |
| Снежный | Ловит снежинки и лепит снеговика |
| Сомелье | Наливает хванчкару в два бокала |
| Пиротехник | Машет волшебной палочкой — искры |
| **Фотограф** | Уходит за кадр и возвращается с полароидом из ваших фото |

## Как добавить фото для кота-фотографа

1. Положи файлы в `photos/` (`1.jpg`, `2.jpg`, …)
2. Открой `photos.js` и допиши пути в массив `PHOTOS`:

```js
window.PHOTOS = [
  'photos/1.jpg',
  'photos/2.jpg',
];
```

3. Закоммить и запушь в `main` — Pages обновится сам.

Пока список пустой, кот показывает нарисованные заглушки (сердечко / силуэт кота).

## Локально

Открой `index.html` в браузере. Для фото через `file://` лучше поднять простой сервер:

```bash
python3 -m http.server 8080
```
