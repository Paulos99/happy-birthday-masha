# С днём рождения, Маша 🎂

Вечерний городок на проектор: тёплое небо, домики с окнами, гирлянды, снег.
В центре — белый стол (торт, Хванчкара, бокалы, тарелки, свечи) и два стула для Павла и Маши.
Коты-официанты ухаживают за столом; кот-фонарщик зажигает свечи; кот-художник пишет поздравления.

**Live:** https://paulos99.github.io/happy-birthday-masha/

## Тексты — `config.js`

Имя, возраст, дата, заголовок, подпись полароида, вино, стулья, пожелания,
комплименты, `paintedGreetings` (что рисует кот-художник), реплики официантов, UI.

## Коты — `drawCat.js`

Отдельный модуль отрисовки (рефы в `refs/`). Можно перерисовать стиль, не трогая сцену.

## Фото — `photos.js`

Одна полароид-рамка «Загадай желание!». Список путей в `PHOTOS`.

## Полный экран

Кнопка-лапка, **F**, двойной клик.
